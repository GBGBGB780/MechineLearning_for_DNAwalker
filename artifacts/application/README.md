# Inference Application Artifacts

This directory is the minimal model bundle for the documented application
workflow. It contains the validation-selected 24k checkpoint for each
architecture, each checkpoint's exact fitted Y scaler, and the split manifest
required by checkpoint provenance validation.

## Included files

| Path | Purpose |
|---|---|
| `cnn/best_mlp_model.seed43.pth` | Validation-selected 24k CNN, seed 43 |
| `cnn/y_scaler.seed43.pkl` | Y scaler bound to the selected CNN checkpoint |
| `transformer/best_transformer_model.seed46.pth` | Validation-selected 24k Transformer, seed 46 |
| `transformer/transformer_y_scaler.seed46.pkl` | Y scaler bound to the selected Transformer checkpoint |
| `split_manifest.npz` | Dataset identity and fixed 24k/validation/test membership required by both checkpoints |
| `SHA256SUMS` | Exact identity manifest for all five binary files |

The split manifest contains provenance, activity summaries, and row indices.
It does not contain the 30k fluorescence curves or target parameter matrix.

## Deliberately excluded

The 30k training dataset, non-selected model seeds, training logs, raw result
trees, and experimental Excel workbooks are not part of this bundle. Therefore:

- prediction and physics refinement on a user-supplied workbook are supported;
- retraining and held-out dataset evaluation require the separately generated
  30k dataset;
- exact reproduction of the reviewed experimental figures requires the
  original licensed workbook.

## Integrity

From this directory, verify every binary before use:

```bash
# macOS
shasum -a 256 -c SHA256SUMS

# Linux
sha256sum -c SHA256SUMS
```

The checkpoints were generated by this repository's locked 30k nested study
from simulator-generated synthetic data. Selection used validation MSE only:
CNN seed 43 and Transformer seed 46. Their embedded dataset SHA-256 is
`f19f0ae0c63a104ea23c96cc83ce5ce1e0d22fd22c5e1a498dfe6ff53418de06`.

PyTorch checkpoints are loaded with `weights_only=True` and explicit device
mapping. The fitted scalers use Python pickle and must only be loaded from a
trusted copy of this release after SHA-256 verification.
